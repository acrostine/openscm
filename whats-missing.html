What's missing in this release

We say it openly: this release of OpenSCM: Open Supply Chain Model is a faithful, readable model, but it is not complete. Below is what is missing or uneven today, measured on the model itself. The next release closes these gaps (see Where it is going in the About).

Measured 16 Oct 2026. Model checks: verifier report of Open Supply Chain Model (OSCM).

1. Descriptions still missing
